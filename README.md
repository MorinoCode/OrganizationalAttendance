# سیستم حضور و غیاب و حقوق پرسنل (Hozor Ghiab)

نرم‌افزار دسکتاپ **کاملاً آفلاین** برای ثبت تردد کارمندان، مدیریت مرخصی، گزارش‌گیری و صدور فیش حقوقی، با تقویم **میلادی** و واحد پول پیش‌فرض **دینار کویت (KWD، سه رقم اعشار)**.

- سه زبان: عربی (RTL)، انگلیسی (LTR)، فارسی (RTL) — بدون هیچ رشتهٔ هاردکد در رابط کاربری
- همهٔ داده‌ها فقط روی همان رایانه می‌مانند: `%APPDATA%\hozor-ghiab\hozor_ghiab.db`
- بدون هیچ درخواست شبکه‌ای در زمان اجرا (بدون به‌روزرسانی خودکار، بدون تلمتری)

## پشتهٔ فناوری

| لایه | فناوری |
| :--- | :--- |
| پوستهٔ دسکتاپ | Electron 45 (Node 24 داخلی) |
| رابط کاربری | React 19 + TypeScript 5.7 + Vite 6 + Tailwind CSS 3.4 |
| وضعیت | Zustand 5 |
| پایگاه داده | **`node:sqlite`** (ماژول داخلی Node) — بدون هیچ ماژول نیتیو و بدون rebuild |
| چندزبانه | i18next 27 + react-i18next |
| اکسل | ExcelJS (به‌صورت `import()` تنبل، فقط هنگام خروجی) |
| تست | Vitest 3 |
| بسته‌بندی | electron-builder 26 (NSIS) |

## دستورها

```bash
npm install          # نصب وابستگی‌ها
npm run dev          # اجرای رابط کاربری در مرورگر (Vite، پورت 5173)
npm run electron     # اجرای کامل برنامهٔ دسکتاپ در حالت توسعه
npm run typecheck    # بررسی تایپ‌ها
npm test             # اجرای تست‌ها (۵۰ تست)
npm run build        # typecheck + ساخت dist/
npm run dist:dir     # بستهٔ اجرایی بدون نصب‌کننده → release/win-unpacked/نظام الحضور والرواتب.exe
npm run dist         # نصب‌کنندهٔ ویندوز → release/نظام-الحضور-والرواتب-<version>-setup.exe
```

> تست‌ها و typecheck بخشی از `npm run build` هستند؛ `npm run dist` همیشه ابتدا build می‌کند.

## امنیت (خلاصه)

- رمز مدیر با **scrypt** در پروسس اصلی هش می‌شود؛ رمز خام هرگز ذخیره نمی‌شود.
- نشست مدیریت در حافظهٔ پروسس اصلی است (۳۰ دقیقه)، توکن در Renderer فقط در حافظه نگه داشته می‌شود و با قفل خودکار ۱۰ دقیقه‌ای بی‌کاری پاک می‌شود.
- همهٔ کانال‌های حساس IPC پشت `requiresAuth` هستند؛ هیچ دادهٔ حقوقی به صفحهٔ کیوسک ارسال نمی‌شود.
- `contextIsolation` + `sandbox` روشن، `nodeIntegration` خاموش، DevTools در نسخهٔ نصبی خاموش و کلیدهای F12/Ctrl+Shift+I مسدود، ناوبری و پنجرهٔ جدید محدود، درخواست‌های دسترسی مرورگر رد می‌شوند.
- هیچ مسیر به‌روزرسانی/اجرای کد از راه دور (Git pull، npm install) وجود ندارد.

## داده و پشتیبان

- مسیر داده: `%APPDATA%\hozor-ghiab\` (فایل `hozor_ghiab.db` با WAL). نصب‌کننده پیش‌فرض برنامه را در `%LOCALAPPDATA%\Programs\hozor-ghiab\` با فایل اجرایی «نظام الحضور والرواتب.exe» می‌ریزد. اگر پوشهٔ قدیمی `%APPDATA%\Hozor Ghiab\` روی سیستم باشد، برنامه همان را به‌عنوان پوشهٔ داده انتخاب می‌کند تا دادهٔ نصب‌های پیشین حفظ شود.
- پشتیبان دستی: تنظیمات → پشتیبان‌گیری (فایل JSON نسخه‌دار).
- پشتیبان خودکار: هنگام بستن برنامه یک کپی باینری از فایل پایگاه داده (پس از `wal_checkpoint`) در `backups/` و نگه‌داری ۳۰ نسخهٔ آخر. این فایل‌های `.db` از راه «بازیابی» داخل برنامه مصرف نمی‌شوند و برای تعویض دستی فایل پایگاه داده‌اند.
- بازیابی، فایل را اعتبارسنجی می‌کند و در صورت ناسازگاری نسخه، بدون دست‌زدن به دادهٔ فعلی خطا می‌دهد.
